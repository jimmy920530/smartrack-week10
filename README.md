# 第十週 SmartRack 完整作業

- `index.html`：可搜尋六篇本地 Wiki 文件的網站示範（**不是**外部 LLM Wiki）。
- `slides.html`：11 頁教學 HTML 簡報，含互動測驗。
- `wiki/`：6 篇需匯入老師指定 LLM Wiki 的 Markdown 原始文件。
- `WIKI_檢查紀錄.md`：已驗證與待驗證項目。
- `WORKFLOW.md`：Loop／Graph 說明。
- `繳交內容_直接複製.txt`：可貼學校作業系統。

## 最快速的公開方式
1. 在 GitHub 建立**新** Public repository：`smartrack-week10`。
2. 將 `index.html`、`slides.html`、`wiki` 六份資料及其他文件上傳；兩份 HTML 必須位於儲存庫根目錄。
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
4. 前往 `https://<你的帳號>.github.io/smartrack-week10/`（Wiki 原型）與 `/slides.html`（簡報）查驗。
5. 若老師提供 LLM Wiki 平台，另外匯入六份 `wiki/*.md`，取得真實 Wiki 連結和查詢截圖。

**請勿將本地檢索網站冒稱為已執行外部 LLM Wiki Ingest。**
